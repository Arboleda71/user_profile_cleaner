# 🧼 User Profile Cleaner

A simple Python script that collects and cleans user input using built-in string methods.  
Perfect for beginners who want to learn how to use `.strip()`, `.lower()`, `.title()`, `.capitalize()`, `.replace()`, and more.

---

## 🚀 What It Does

- Prompts the user to enter their **name**, **email**, **city**, and a **short comment**.
- Cleans and formats the input for consistency.
- Displays a neat summary of the formatted profile.

---

## 💻 Technologies Used

- Python 3
- Built-in string methods (no external libraries)

---
